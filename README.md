# 💧 Water Diary

A simple water diary built with HTML, CSS, and JavaScript to track glasses of water through an interactive counter.

## ✨ Features
- ➕ Add a glass of water with a button click.
- 🔢 Keep track of the total glasses counted during the current session.
- 🎨 Simple and beginner-friendly interface.

## 🛠️ Technologies Used
- 🌐 HTML
- 🎨 CSS
- ⚡ JavaScript

## 📚 What I Learned
- 🧩 Using JavaScript functions.
- 🖱️ Updating a counter through button clicks.
- 🔗 Connecting HTML buttons to JavaScript.
- 🖌️ Styling a webpage with CSS.

## 🚀 Future Improvements
- 💾 Save the water count using `localStorage`.
- 🎯 Add a daily water goal.
- 🌟 Improve the design and user experience.
